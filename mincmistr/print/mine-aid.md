## Mincmistr mine choice aid

**Choose the tile.** Take the drawn tile with the highest stars + ore + VP. Break ties by more stars, then first drawn.

**Compare rows.** Use only rows with a legal, affordable space. Count rock stars in the row total. Rank each player's own stars to find their award. Players with zero stars score zero. Tied players each get the full award for their place and use up the tied places.

| Table size | Total stars in the row | VP by place |
| --- | --- | --- |
| 2 players | 0–3 | 2 / 0 |
| 2 players | 4–6 | 4 / 1 |
| 2 players | 7+ | 6 / 2 |
| 3–4 players | 0–5 | 2 / 1 / 0 |
| 3–4 players | 6–9 | 3 / 2 / 1 |
| 3–4 players | 10+ | 5 / 3 / 2 |

**Journeyman, Master and Grandmaster.** For each candidate row, subtract its current award from its award with the tile added. Choose the biggest gain, then the cheapest space, then the row where it has the fewest mines, then the arrow.

**Apprentice.** Use the same tile choice. Skip the award calculation. Choose the row with the fewest of its mines, then the cheapest space, then the arrow.

**Arrow.** ◀ picks the first space in reading order (top to bottom, left to right). ▶ picks the last.

Discard the draw if placement is impossible. Technology and both Mine actions from St. Barbara tile 9 use the same placement priorities at no wood cost. Use reserve miners first for those free mines.

Mincmistr v1.2.5, rules 5.2, 6.4, 6.5, 7 and 9. Mine scoring follows the table printed on the Kutná Hora board.
